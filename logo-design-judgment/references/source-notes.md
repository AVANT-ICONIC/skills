## Cross-cutting overlaps (confidence signals)

- 3-second recall test: items 7 and 11 (and V1's test battery) - repeated, so a core creator tool.
- Keyword-pair method: items 10 and 11.

## Application checks (does the learner hold the judgment?)

Given a new concept, run: small-size, blur, 3-second recall, adjectives-vs-brief, niche-mix lineup,
ownability gap, context mockup at smallest real placement, brand-name removal, gradient-off flat
test. Given a brief: write the one-sentence filter, 3 keyword pairs, the conform-vs-contrast color
decision, and the emotion each concept must evoke. Given a wordmark: look for a negative-space
opportunity tied to a keyword; check optical (not just mathematical) alignment; check it is not one
of the seven overused defaults without a reason.

literal logos fall into obscurity (Silverback counterexample: no mountain, no bike, slanted
logotype for motion). Color: origin palette (IKEA/Sweden), conform-vs-contrast in the industry,
emotion pairs (FedEx orange action + purple calm). Presentation craft: restate good-logo attributes
and the client's problem first; brand-color split screen; human mockups; show the audience
interacting with the mark; the logo is for the audience, not the client; selling the idea matters
as much as the design.
