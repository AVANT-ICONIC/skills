# Recovery, budgets, and host adapters

## Single-agent recoverability
- On technical failure inspect concrete error; try an authorized alternate observer (e.g. another installed renderer, direct file inspection) without guessing that a DOM parser proves Canvas pixels.
- At a genuine turn/tool budget or unavailable capability, preserve best artifact, revision, failing gates, last real observations, attempted techniques and the next executable operation; report `CHECKPOINTED` or `BLOCKED`, not PASS.
- Reopen and reobserve the stored candidate on continuation. Do not reuse earlier review evidence to approve a different revision.
- When two materially different attempts fail on the same defect, change approach or explain plateau. No infinite retries with identical inputs or costly unapproved services.
- If no appropriate image-observation tool is exposed in a given host, honest NOT_EVALUATED is mandatory; a strict instruction does not create a missing API.

## Platform enforcement
- **Pure Markdown skill**: advisory behavior. Its instructions alone cannot intercept tool execution or prevent a response.
- **Runtime hooks**: use a host-specific stop/tool hook only after verifying that host's current APIs and limits. For generated image/render events mark candidate UNREVIEWED; on latest revision evidence approval allow terminal completion; otherwise reject the release or require an honest incomplete status. Never block safety refusal, user interruption, tool budget exhaustion or genuine missing permission.
- **CI/project tooling**: run validator and artifact-specific tests for configured required scopes; do not rely on text self-attestation. Repo branch protection is a separate policy.
- **ChatGPT WebUI**: the skill can direct same-turn observe/repair when tools expose results, but cannot guarantee an additional turn after a generation tool that auto-terminates. Use the WebUI adapter for available tool routes and actual evidence limits, not invented hooks.
- **Apex**: existing gauntlet runtime is independent and may cap passes; do not claim Anti-SlopRush silently raises its limits. Integrate the receipt gate separately before promotion.

No provider, paid API, GitHub account, browser, local OS or extra agent is a mandatory dependency.
