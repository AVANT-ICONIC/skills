## Newly implemented

- Server supports externally issued OAuth bearer tokens with RS256 JWT signatures; issuer, audience, scope social:read, allowed subject, and expiry are checked. Unknown attacker-provided JWT key IDs do not cause forced JWKS refresh. No identities/secrets committed.
- External bind defaults fail-closed; only explicit private-network exception allows unauth container bind, still mapped to localhost on the host.
- Maximum two simultaneous URL acquisitions and six starts per minute, with active-job protection from cache eviction.
- Authorized Reddit Data API module (disabled without approved user app credentials): single post, capped nested comments, conditional crosspost v.redd.it video fallback, in-memory refresh of approved OAuth access token.
- Real MCP client accepts the returned **image content**, not a local path. Extracted pictures remain labelled as sampled source frames; they are NOT continuous motion or proof of audio inspection.

## Exact unavailable capabilities

- ChatGPT current session is NOT connected to a deployed Social Watch MCP server. GitHub Actions demonstrates protocol usability but is an ephemeral runner.
- No approved Reddit app/token was supplied to CI, so Reddit authorized module was mocked/tested, not live API tested.

- Access to **every** post on any platform is not technically guaranteed even with full authorization (private, deleted, geo-/age-restricted, removed, rights-managed posts).

## Deployment / account gate

Follow bridge/AUTH-DEPLOYMENT.md. A real external OAuth provider with proper login/consent is required before public connection, as is host-level egress/SSRF hardening and a permitted MCP connection in ChatGPT. Currently public OpenAI documentation lists full custom MCP support for Business and Enterprise/Edu; Pro read/fetch may be available. Do not infer Plus has custom MCP access. If account policy blocks the connection, a skills-only plugin is NOT an equivalent substitute.

3. Legitimate platform auth added/tested where required, with changed platform migration policy respected.
4. Standard/paid external providers remain opt-in only; no hidden credit spend.
5. CI green plus explicit per-platform evidence (no silent PASS status on platform failures).
